# 👔 电子衣柜 (Wardrobe)

智能穿搭推荐系统 — 根据你的衣物自动推荐今日穿搭。

## 项目结构

```
wardrobe/
├── frontend/          # React 前端 (Vite + TypeScript + Tailwind)
│   ├── src/
│   └── package.json
├── backend/           # Express 后端 (TypeScript)
│   ├── src/
│   └── package.json
└── README.md
```

## 技术栈

- **前端:** React 18 + TypeScript + Vite + Tailwind CSS
- **后端:** Node.js + Express + TypeScript
- **数据库:** PostgreSQL (Supabase)
- **部署:** Vercel + Render

## 快速开始

### 前端开发
```bash
cd frontend
npm install
npm run dev
```

### 后端开发
```bash
cd backend
cp .env.example .env
npm install
npm run dev
```
